This is Cameron Clark's portfolio site. It is built with React, Vite, Tailwind CSS, and TanStack Router.

## Getting Started

First, run the development server:

```bash
pnpm dev
```

Open the local URL printed by Vite, usually [http://localhost:5173](http://localhost:5173).

## Build

```bash
pnpm build
```

## Formatting

```bash
pnpm format
```

Routes are defined in `src/router.tsx`. Page components live in `pages/`, and shared layout components live in `components/`.
